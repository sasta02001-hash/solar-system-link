Solar System Link POS 0.6.8-r1 安裝精靈（手動分享開發測試版）

需要 Windows 7 SP1 x64 或更新的 x64 Windows，以及 .NET Framework 4.8。
請由普通 Windows 檔案總管雙擊安裝 EXE，依歡迎、安裝進度、完成三個畫面操作。
若系統尚缺 .NET Framework 4.8，先依原管理流程安裝；本包不下載或改動系統必要元件。
官方來源：https://dotnet.microsoft.com/en-us/download/dotnet-framework/thank-you/net48-offline-installer
ZIP 備用包也提供 StartInstaller.vbs，可先顯示中文必要需求提示後開啟同一個安裝精靈。

舊版保留
請先正常停止分享並關閉自己開啟的被控端。新版使用獨立 POS-0.6.8-r1 目錄、捷徑與移除項目，不卸載或覆寫 0.6.0／0.5.1。
固定六碼、裝置身分與安全紀錄保留於原帳戶資料；安裝器不讀取、複製、重設或變更這些秘密資料。
請使用平常操作 POS 的相同 Windows 帳戶。若舊資料損壞，保留原資料尋求修復，勿刪除 DPAPI、鎖定或交易檔案。

安裝完成
精靈會先核對程式、安裝清單及桌面／開始功能表捷徑才顯示完成。
完成頁的「完成後開啟程式」選項預設不勾選；開啟程式也不會自動開始分享。
使用桌面「Solar System Link POS 0.6.8」捷徑，再由本人按「開始分享」。每次連線仍須本機允許滑鼠與鍵盤控制。
這一版不是完整 SSS，不包含無人值守或自動開機連線；不變更 SSS 信任與操作許可規則。

失敗與移除
安裝途中不要強制結束安裝程序。若顯示錯誤，依畫面正常關閉自己開啟的被控端或其他安裝視窗，再用同一個原安裝包重試。
未知、被修改或被占用的檔案會保留。需要移除時，使用 Windows 程式清單的「Solar System Link POS 0.6.8」。
移除只處理本版已核對的程式／捷徑，保留舊版、固定碼、身分與其他使用者檔案。

實機限制
本地建置、圖示與隔離測試不代表 Windows 7 POS 已安裝、持續操作或 SSS 整合已通過。
先使用空白記事本確認，勿以收銀、付款或客戶資料作測試。
需要可互通區網或既有 VPN，TCP 45731；鎖屏、UAC 安全桌面與高權限程式不支援遠端操作。
