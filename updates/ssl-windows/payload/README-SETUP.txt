Solar System Link 0.7.0-r1｜Windows x64 自動更新安裝精靈（開發測試候選）

此 0.7.0 候選加入主控連線前的本機 SSS 檢查，以及認證後的對端 SSS 檢查與新鮮證據門檻；無法確認時會維持封鎖。
SSS 的最新版與背景狀態檢查，不代表 Native C1 安全功能或 POS 實機已驗收。0.6.9 因實際通訊流程問題已淘汰，不應發布或部署。

同一安裝包會在本機偵測 Windows 真實版本、原生架構與 .NET Framework Release，不依瀏覽器或網站猜測。
Windows 7 SP1 x64：僅提供 POS／被控端候選。Windows 10／11 x64：可自行選擇主控或被控角色。
上述角色使用相同 .NET Framework 4.8 x64 執行期，不提供假冒的 32 位元或 ARM 版本；Server 與其他系統不會自動安裝。
請先依原管理流程備妥 .NET Framework 4.8。完全沒有適用 .NET 執行期時，Windows 可能先顯示標準 runtime 提示；精靈不自動安裝先決元件、不提權。

請從平常使用帳戶的普通 Windows 檔案總管雙擊安裝 EXE。依序查看系統、選擇用途、按「開始安裝」、等候實際結果。
安裝原固定可信 bootstrap 五檔、已簽署執行期七檔，以及獨立 POS 啟動器。
既有更新根已存在時只接受原固定 bootstrap；版本與 pending 由原更新引擎處理，不刪除或降低 current／歷史高水位。
舊 0.6.8／0.6.0／0.5.1 程式及捷徑保留。固定六碼與身分沿用 normal DirectDevice-v1；精靈不搬移、解密、重設或匯出這些資料。
本次會建立所選角色的「自動更新」桌面及開始功能表捷徑；請使用新捷徑開啟。

POS 自動更新：先確認較新版本的維修簽章；操作允許仍開啟時延後。
接續程序確認就緒後正常結束舊視窗，等舊程序真退出，再由原更新器檢查更新。
更新成功或已知失敗都重新驗證 current 再開啟；結果不明時不強制結束、不啟第二次、不碰撞重開。
若更新前已開始分享，短期同帳戶一次性意圖可恢復分享；滑鼠鍵盤允許與 SSS 授權不會自動還原。
可在「設定與疑難排解」關閉自動更新、立即檢查或取消本次交接；沒有建立服務、排程或開機自啟。

這不是完整 SSS 防火牆，也不代表 SSS Ready。每次連線仍須依被控端有效授權操作；此候選不自動勾選操作允許。
無人值守、Windows 7 POS 實機連線、鍵鼠及持續操作尚未完成驗收。本機隔離測試通過不能代替實機結果。
MAC 工作仍另行處理。安裝及更新不收取額外費用；不包含任何私鑰、六碼、配對設定或發布設定。
