SSS 單檔安裝器 0.5.0-r1（開發測試版）

下載 SSS-Setup-050-r1.exe，於符合條件的 Windows 電腦雙擊執行。
這是一個單檔安裝入口，內嵌既有 SSS 0.5.0.0／sequence 7 材料；不是新的 SSS 執行版本或新的簽署目錄。原有發行資產不覆寫。

來源層適用條件：Windows 7 SP1 x64，或 Windows 10／11 x64（build 19041 以上），一般使用者權限；必須已安裝 .NET Framework 4.8，並可取得有效官方版本。未提供 x86、ARM64、macOS 或 iOS 安裝包。
.NET Framework 4.8 未內附；缺少 CLR4 的電腦不能進入此 managed 安裝精靈。

全新電腦由原始安裝流程建立資料；既有安裝沿用原身分、設定與原更新器的正常更新流程。只有驗證目前簽署版本及背景啟動結果都成功才可顯示完成。失敗、未知或取消不當成功，不強制結束原程序，也不重建既有身分。
既有版本低於 0.4.9.0，或更新器回覆 11、缺少合格的正常退出／移轉入口時會停止；這個缺口尚未閉合。

限制與驗證範圍：
- 未加 Authenticode 簽署。EXE 的 SHA256 用於核對交付檔案，不是新信任根；內嵌材料仍由原始簽署目錄與原更新路徑驗證。
- 已完成來源獨立覆核、候選編譯、12 項有界資料檢查及內嵌原始材料核對；本次發布流程只驗證交付檔案。
- 普通 Windows 安裝、Windows 7／POS、SSL 更新重啟重連、鍵鼠／IME 持續操作與完整原生防護尚未完成驗收。
- 發行為 prerelease 開發測試版，不宣稱穩定正式版、所有作業系統可用或 99／100 分。
